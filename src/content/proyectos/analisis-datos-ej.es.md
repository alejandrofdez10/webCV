## Contexto

Este es un proyecto de ejemplo para mostrar cómo se estructuran los contenidos en el portfolio. Reemplaza este fichero (y su versión en inglés) con tu proyecto real.

## Qué hace

- Ingiere datos desde CSV / API
- Limpieza y transformación con Pandas
- Modelado predictivo con Scikit-learn
- Dashboard interactivo con Plotly

## Resultados

- Reducción del 30% en tiempo de análisis manual
- Precisión del modelo: 92% en test set

## Cómo reproducirlo

```bash
pip install -r requirements.txt
python pipeline.py
```
